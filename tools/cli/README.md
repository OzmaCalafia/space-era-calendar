# Space Era Calendar CLI

A command-line interface tool for converting and auditing time using the Space Era Calendar Standard.

## Installation

```bash
npm install
chmod +x bin/cli.js
```

## Usage

* **Current Time:** `space-era today`
* **Date Conversion:** `space-era ce <YYYY-MM-DD>`
* **Phase 1 Analysis:** `space-era phase1 <YYYY-MM-DD>`
* **Phase 2 Analysis:** `space-era phase2 <YYYY-MM-DD>`
* **Migration Offset:** `space-era migrate <YYYY-MM-DD>`
* **Version Info:** `space-era --version`
