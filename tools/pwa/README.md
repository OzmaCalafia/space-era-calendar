# Space Era Calendar PWA

A production-ready, offline-first Progressive Web Application (PWA) for the Space Era Calendar Standard, built with Vanilla JavaScript and Vite.

## Features

- **Live Interplanetary Clock:** Real-time visualization of standardized Space Era time.
- **Decimal Converter:** Bidirectional timestamp translation engine.
- **Embedded Documentation:** Dynamic Markdown parser rendering the core standard specification (`README.md`) directly in-app.
- **Asset Export:** Direct-download integration for the official PDF specification (`THE SPACE ERA CALENDAR STANDARD v1.0.pdf`).
- **Offline Resilience:** Service worker caching for reliable standalone usage.

## Development Setup

1. Install dependencies:
    npm install

2. Run the local development server:
    npm run dev

3. Build the production bundle:
    npm run build

4. Preview the production build locally:
    npm run preview
