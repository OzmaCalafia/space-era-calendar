# Space Era Calendar (JavaScript)

Official JavaScript/Node.js implementation of the Space Era Calendar Standard (v1.0).

## Usage

    import { SpaceEraDate } from './src/core.js';

    const date = new SpaceEraDate(1947, 2, 20);
    console.log(date.toDualString()); // 0001 SE / 1947-02-20 CE
